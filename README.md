# rock-paper-scissors

A simple browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript to practice DOM manipulation, basic logic, and string handling. Project is part of The Odin Project
curriculum.

Features

Three Buttons – Choose between Rock, Paper, or Scissors.

Score Tracking – Keeps track of both player and computer scores.

Hand Display – Shows the selected hands for both the player and the computer.

Round Replay – Replay a round without reloading the page.

Built With

HTML for structure

CSS for layout & styling

JavaScript for interactivity (event listeners, DOM manipulation, and game logic)
